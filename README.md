# MachMind360

A responsive company website for MachMind360, featuring its restaurant POS product and the Mavalli Biryani Dharwad implementation showcase. The interactive POS workspace is available at `/pos-demo`.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## POS demo

Open `/pos-demo` in the local Vite site to explore the dashboard, billing, order management, tables, inventory, and reports. The demo uses local React state and sample menu, sales, and stock data only. It does not connect to a restaurant database or process payments.
